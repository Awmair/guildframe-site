# Approve the margin on each reward.

Guide: https://guildframe.com/guides/board-game-kickstarter-reward-pricing
Author: Umair at Guildframe
Updated: 2026-10-28

- [ ] Compare the core and deluxe reward side by side.
- [ ] Check packed dimensions as well as product weight.
- [ ] Test bundles with the actual quantities and discounts.
- [ ] Keep stock allocated across rewards and add-ons consistent.

## Planning example

Compare a core box with a deluxe box that adds a playmat. Ask for the packed size of both. If the mat changes the parcel bracket, include that difference before choosing the upgrade price. Check whether a discounted bundle leaves enough contribution after the additional handling.

## Check your work

Reconcile the pricing sheet with the final reward contents and the fulfilment quotes.
