## Planning example

Create a test order containing a base game, an expansion and a language selection. Change the destination country, then check the order summary and export. Compare the output with the warehouse import format, including quantities, paid status and the correct item identifiers.

## Check your work

The fulfilment partner should be able to identify and process each test order without guessing.
