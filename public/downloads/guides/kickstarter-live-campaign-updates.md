# Answer backer questions without making unapproved promises.

Guide: https://guildframe.com/guides/kickstarter-live-campaign-updates
Author: Umair at Guildframe
Updated: 2026-10-28

- [ ] Keep one queue of recurring questions.
- [ ] Confirm production facts with the responsible supplier or owner.
- [ ] Record which public pages need the same correction.

## Planning example

If a backer asks whether a tray fits sleeved cards, get a measured answer before adding it to an update. If the fit is still being tested, say so. Once confirmed, update the reward description and FAQ too; otherwise the campaign will contain conflicting answers.

## Check your work

A useful update tells backers what changed, what it affects and when the next confirmed information is expected.
