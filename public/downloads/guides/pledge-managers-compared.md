# Test your messiest order in each pledge manager you shortlist.

Guide: https://guildframe.com/guides/pledge-managers-compared
Author: Umair at Guildframe
Updated: 2026-11-25

- [ ] Write down your most complicated order, with edition, language, add ons and destination.
- [ ] Note where you funded, because that narrows the tools before fees do.
- [ ] Estimate survey spend on add ons and shipping, then apply each published fee.
- [ ] Ask each vendor for any processing figure its pricing page leaves out.
- [ ] Compare each tool's order export with your warehouse import format.

## Planning example

Hypothetical example: backers are expected to spend $10,000 on add ons and shipping in the survey. A 3% fee costs $300 and a 5% fee costs $500, before processing. Then build a test order with a base game, an expansion and a language choice, change the country, and check the export your warehouse would receive.

## Check your work

Your fulfilment partner should be able to read the test export without asking what any code or paid status means.
