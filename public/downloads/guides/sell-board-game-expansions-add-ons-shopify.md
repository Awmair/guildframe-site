# Help customers buy compatible products.

Guide: https://guildframe.com/guides/sell-board-game-expansions-add-ons-shopify
Author: Umair at Guildframe
Updated: 2026-10-28

- [ ] State which base game or edition an expansion requires.
- [ ] Separate product variants from additional products.
- [ ] Check stock accounting for bundles.

## Planning example

An expansion that requires the second edition should say so beside the purchase controls and in the description. When a bundle sells, confirm that the underlying stock is adjusted correctly. Otherwise the store can continue selling a component already allocated to a bundle.

## Check your work

Test a compatible combination, an incompatible combination and an out-of-stock component.
