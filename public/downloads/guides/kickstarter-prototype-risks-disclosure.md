# Show what exists and what still needs work.

Guide: https://guildframe.com/guides/kickstarter-prototype-risks-disclosure
Author: Umair at Guildframe
Updated: 2026-10-28

- [ ] Label renders, prototypes and production samples accurately.
- [ ] List unresolved production dependencies.
- [ ] Give each risk a next verification step.

## Planning example

A painted render and a resin test print answer different questions. Put the label beside the image and explain what the print test established, such as scale or fit. Do not imply that testing one component proves the final factory production run is ready.

## Check your work

Every production claim should have an owner and evidence that matches the claim's scope.
