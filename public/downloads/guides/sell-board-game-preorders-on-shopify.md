# Make the order's timing and payment terms clear.

Guide: https://guildframe.com/guides/sell-board-game-preorders-on-shopify
Author: Umair at Guildframe
Updated: 2026-10-28

- [ ] Label preorders near the purchase action.
- [ ] Explain payment timing and cancellation terms.
- [ ] Test mixed carts and delayed fulfilment messages.

## Planning example

If a customer buys an in-stock card deck and a preorder expansion, decide whether the order ships together or separately. State that decision before checkout. Test the confirmation message so it does not imply immediate dispatch for an item that is still in production.

## Check your work

A customer should be able to find the expected delivery window and contact route after checkout.
