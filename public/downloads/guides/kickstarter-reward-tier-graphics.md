# Help a backer see what changes between tiers.

Guide: https://guildframe.com/guides/kickstarter-reward-tier-graphics
Author: Umair at Guildframe
Updated: 2026-10-28

- [ ] Keep common contents aligned in the comparison.
- [ ] Call out the added items rather than repeating every label.
- [ ] Match names and prices to platform settings.

## Planning example

If the deluxe tier adds metal coins and a playmat, show those additions together while keeping the core game in the same position. Avoid using a larger box image as the only signal of value. State whether the picture includes optional extras or items supplied separately.

## Check your work

Check that the written reward list and the graphic can be understood independently.
