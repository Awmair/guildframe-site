## Planning example

Test a core game with an expansion, a long rules description and several product images. A theme that looks attractive with a single poster image may struggle with compatibility information. Compare the total setup work and ongoing app costs alongside the theme's licence price.

## Check your work

Use the same products and tasks in every trial so the comparison is meaningful.
