- [ ] State the system and any required books.
- [ ] Show readable sample pages and a session premise.
- [ ] Separate PDF, print and accessory rewards.

## Planning example

A campaign for an adventure should identify whether it is a complete game or needs another ruleset. Show a useful spread, such as a location and encounter, instead of only cover art. If the print tier also includes a PDF, state when each format is expected to arrive.

## Check your work

Ask a game master what they would need to bring to run the first session.
